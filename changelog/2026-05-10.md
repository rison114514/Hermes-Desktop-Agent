- 重写 `README.MD`，补齐 Windows 原生前端、WSL Hermes ACP 后端、历史 session、git worktree、自定义 worktree 目录和目录选择器的最新使用说明。
- 新增根目录一键启动脚本 `start-hermes-desktop.cmd`，方便在 Windows 文件资源管理器中双击启动。
- 修复一键启动脚本双击无反应的问题：不再依赖 PATH 中的 `powershell.exe`，改为优先使用系统绝对路径，并在启动失败时暂停窗口显示错误。
- 调整 worktree 目录选择语义：`Browse` 选择父目录，实际 worktree 创建到 `<父目录>/<name>`，避免 git 因目标目录已存在而失败。
- 为 worktree 创建增加同名冲突处理：当 `hermes/<name>` 分支或目标目录已存在时自动追加数字后缀。
- 新增普通工作目录切换功能：右侧 `Workspace` 卡片提供 `Change`，选择目录后刷新文件树和路径信息，并在新目录启动新的 ACP session。
- 新增普通工作区刷新按钮：右侧 `Workspace` 卡片可手动刷新当前文件树和路径快照。
- 调整窗口置顶策略：默认不再置顶，旧的本地窗口状态会迁移为非置顶，点击其它窗口后其它页面可以正常显示在前方；标题栏和托盘仍保留手动置顶开关。
- 新增 `scripts/start-windows.ps1`，封装 Windows 启动流程：
  - 检查 Node.js、npm、WSL 和 Hermes ACP。
  - 自动设置 `HERMES_WSL_DISTRO`，默认 `Ubuntu-22.04`。
  - 缺少 `node_modules` 时自动执行 `npm install`。
  - 缺少构建产物或显式传入 `-Build` 时自动执行 `npm run build`。
  - 最后启动 `npm run electron:windows`。
